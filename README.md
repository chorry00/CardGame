# とる？パス！
スマホ対応のカードゲーム。あなた1人とCPU2〜6人で対戦します（初期設定は5人）。CPUは連番重視・チップ温存・慎重派・大胆派・収集家・戦略家の異なる判断基準で行動します。外部パッケージ不要、Node.js 18以上。

## 起動
```sh
npm start
```
ポート3000で配信します。`PORT` 環境変数で変更可能です。スマートフォンから公開する際は、HTTPS対応のホスティングに配置してください。

## 検証
```sh
npm test
```
指定ルールに従い、24枚のカード・人数別チップ・非公開の相手チップ・連番得点・同点優勝に対応。対人通信、途中保存は未実装です。

## スマートフォン / PWA
HTTPSで公開したURLをスマホで開いてください（ローカル開発ではlocalhostも利用可能）。
- Android: 対応ブラウザのインストールボタン、またはメニューの「アプリをインストール」。
- iPhone / iPad: Safariの共有メニュー →「ホーム画面に追加」。
- 「オフラインで遊べます」と表示された後は、通信なしでも起動・CPU対戦できます。初回は通信が必要です。
- 新版公開時は `sw.js` の `CACHE` を更新してください。利用者が更新を選ぶと適用します。対戦中に自動再読み込みしません。
- アプリを閉じたり再読み込みした場合、進行中の対戦は保存されません。

本番では `server.js` の公開ポートをHTTPSリバースプロキシで配信するか、HTML/CSS/JS、manifest、sw.js、iconsを同一オリジンのルートへ静的配信してください。

## GitHub Pages公開
公開URL: https://chorry00.github.io/CardGame/

リポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定します。
`main` へのpush、または Actions → Publish card game → Run workflow でテスト後に静的ファイルを公開します。
初回push時にPagesが未設定だった場合、設定後にRun workflowを実行してください。
サブディレクトリ `/CardGame/` とローカルの `/` の両方で動作する相対パスを使用しています。
